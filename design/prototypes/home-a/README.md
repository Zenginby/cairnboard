# Home A

A workspace-led bento dashboard follows the supplied reference: hero and mini calendar, selected project covers, ongoing work beside the board summary, then today's entries, pinned notes, recent quick notes and research. It uses three columns from 1100px, two from 700px, and one below; phones place today's entries and ongoing work immediately after the hero.

- Preview: `npm run design:serve`, then `http://127.0.0.1:4391/prototypes/home-a/`.
- Shell: the same local `shell.css`/`shell.js` as Board A, with a material header, four-tone logo, approved pill indicator, search and a theme popover containing the existing theme selector and **Hareket: az**. Below 900px the navigation scrolls inside its own row and search becomes an icon button. The extra tabs link to Home sections; project covers and the board summary link to Board A.
- Interactions: **Projeleri seç** filters the project covers, remembers a validated ID list in localStorage with guarded reads/writes, and supports defaults/all/none. Calendar and journal links open or reach today's entries; note/research rows open local previews. Journal submission adds a numbered row and updates the last-record count. All prototype states remain available; fixture switches reset in-memory edits without resetting the chosen project list.
- Keyboard: `N` quick note, `C` new card, `/`, `⌘K` or `Ctrl+K` search, `?` help, `M` on an ongoing card to move it. Escape closes dialogs/popovers; project checkboxes use native Tab/Space. Keyboard-opened dialogs/popovers are instant. Character shortcuts leave input typing alone.
- Motion: boxes fade/translate on first load only, with delays limited by `--motion-stagger-max-items`. Ring arcs reveal once through two rotating SVG masks; the static arc length comes from a CSS custom property set with `style.setProperty`. Link boxes use the approved spring lift; new journal rows fade/translate in. Only transform/opacity animate. The last-record dot is the only recurring content motion; reduced motion disables its pulse and ring/box movement, retaining short fades. Changing the motion preference cancels active programmatic motion.
- Fixtures: the snapshot is 3 November 2026 at 17:15, with 6 ongoing cards, 8 waiting cards, 8 entries today, 19 journal days and 12 research documents. Project summaries include explicitly fictional archived completion/note totals; these make the Home summary 177 cards and the first project 13/15 completed. Board A retains its independent, smaller card fixture. Neither page writes Markdown or shares live edits across navigation. The calendar reports the actual 3 November entry days, with the other 16 days in October.
- Tokens: all colors, gradients, spacing, radii, shadows and motion use approved tokens; the header is 56px and content cap is 1104px through spacing arithmetic. The hero is 64px/44px through typography arithmetic. **700 weight cannot be expressed by the existing tokens**: it uses the approved maximum 650 rather than introducing a raw weight. The supplied 700/900/1100px responsive breakpoints and SVG viewBox geometry are structural values, not new styling tokens.
- Proposed shared changes: a responsive navigation shell with a theme popover, a project-selection checklist without completed-task strike-through, a transform-only circular progress component, and a hero weight token if 700 is required. Shared files are unchanged; the shell is duplicated locally to respect the folder boundary.

These temporary previews do not exercise the production CSP or real HTTP asset loading. Direct served-page visual review, ring clipping and real-device interactions remain for the coordinator.
